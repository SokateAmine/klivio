# 🎓 KLIVIO - Intégration Web (Reproduction Figma)

Ce projet est une intégration **"pixel-perfect"** (reproduction fidèle) d'une maquette Figma. Il s'agit de la page d'accueil d'une plateforme fictive d'apprentissage en ligne spécialisée dans le développement personnel, nommée **KLIVIO**.

> **Note :** Cette version du projet a été entièrement refactorisée en utilisant **Tailwind CSS** pour garantir un code plus moderne, maintenable et un design système cohérent.

---

## 📝 Description du projet

L'objectif était de transformer un design statique complexe (Figma) en une page web fonctionnelle et parfaitement responsive. Le défi principal consistait à passer d'une structure CSS classique à une approche **Utility-First** avec Tailwind.

---

## ✨ Fonctionnalités et Sections intégrées

* **En-tête (Header) :** Barre de navigation avec barre de recherche, liens d'authentification et menu burger optimisé pour le mobile.
* **Bannière (Hero Section) :** Accroche principale avec CTA et gestion des dégradés complexes via Tailwind.
* **Catalogue de Formations :** Grilles dynamiques (Grid) pour les formations "Populaires" et "Récentes".
* **Preuve Sociale :** Section d'avis clients stylisée.
* **Avantages & Création :** Présentation des bénéfices élèves/formateurs avec une mise en page structurée.
* **Contact :** Formulaire de contact moderne avec gestion des états `focus` et `hover`.
* **Pied de page (Footer) :** Liens utiles, réseaux sociaux et mentions légales.

---

## 🛠️ Technologies Utilisées

* **HTML5** : Structure sémantique et accessible.
* **Tailwind CSS** : 
    * Mise en page via **Flexbox** et **CSS Grid**.
    * Gestion des couleurs et dégradés (Gradients) personnalisés via `tailwind.config.js`.
    * **Responsive Design** natif (utilisant les préfixes `md:`, `lg:`, etc.).
* **Typographie** : Intégration de la police **Montserrat**.
* **Icônes** : Utilisation de **FontAwesome**.
